# Manuscript

`paper_v1.tex` is the manuscript. `paper_v1.pdf` is the compiled 5-page output
(US Letter, 612 x 792 pt) and is the file to submit.

Build it with any LaTeX engine; the class file `IEEEtran.cls` is included:

```bash
tectonic -X compile paper_v1.tex     # or: pdflatex paper_v1.tex
```

The four figures it embeds are in this directory and are regenerated by
`src/09_paper_figures.py` (fig1_coverage.png) and
`src/09b_paper_figures_unseen.py` (fig3b, fig4b, fig5b). Filenames encode an
earlier six-figure layout, so they do not match the printed numbers: fig3b
prints as Fig. 2, fig4b as Fig. 3, fig5b as Fig. 4. The manuscript refers to
every figure with `\ref`, never a literal number. See `docs/FIGURES.md` for
the full figure to code to data map.

The other PNGs here (fig2_regimes, fig3_calib_dca, fig4_covid, fig5_fairness,
fig6_tabpfn) are supplementary: they are produced by the same scripts and are
not embedded in the manuscript. Their results are reported numerically in
`docs/RESULTS.md`.

For the Overleaf package, use `overleaf_submission.zip`, which carries a flat
copy of the source, the class file and the four embedded figures.
