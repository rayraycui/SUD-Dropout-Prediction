# data/

## Committed

| file | rows | what |
|---|---|---|
| `teds_d_analysis_2015_2022.parquet` | 6,679,648 | the analysis table: 15 features, binary outcome `y`, `subname`, `year`. Built by `src/01_build_analysis_table.py` from the raw files in `raw/`. |
| `teds_d_class_sizes_2015_2022.csv` | 17 | episodes and dropout rate per substance, with the high-volume / lower-volume grouping (`BIG6` / `small` in the `group` column). Regenerated by `src/16_build_tables.py`. |
| `p1_plan_eval_17substance_gbt_vs_logistic.csv` | 17 | **the results file behind Table III, Fig. 1 and Fig. 2**: per-substance AUROC under both training strategies and both learners, with bootstrap intervals and verdicts |
| `p1_plan_eval_17substance.csv` | 17 | boosting results alone (same run) |
| `p1_plan_eval_17substance_logistic.csv` | 17 | logistic results alone (same run) |
| `p1_early_stopping_sensitivity.csv` | 51 | every substance refitted under `early_stopping` auto / off / on |
| `p1_categorical_sensitivity.csv` | 85 | declared categoricals versus plain integer codes, plus three code permutations |
| `p1_categorical_verdicts.csv` | 11 | bootstrap verdicts for the eleven lower-volume substances under categorical splits |

`p1_plan_eval_17substance_gbt_vs_logistic.csv` is the file to read first. One row per
substance; `group` marks whether it is in the pooled training set; `gbt_delta` is pooled
minus substance-specific, so positive means pooling helps.

## Not committed

`raw/` holds the TEDS-D public-use files, which SAMHSA distributes and this repository does
not redistribute. `raw/MANIFEST.csv` pins the exact bytes used (URL, size, SHA-256, parsed
shape per year) so a rebuild can be verified. Run `python src/00_download_teds.py` to fetch
them.

## Cohort definition

6,679,648 episodes, dropout rate 0.397, across 17 primary substances,
discharge years 2015-2020 and 2022. 2021 is excluded because its public-use CSV ships text
labels rather than numeric codes. TEDS-D SUB1 code 19, *other drugs* (37,578
episodes), is excluded as a heterogeneous residual category rather than a specific
substance class.

## Consistency

`src/17_check_consistency.py` asserts that all of the above agree with each other and with
the manuscript: substance names match `p1_plan_eval_17substance_gbt_vs_logistic.csv`
exactly, class sizes sum to the cohort, the high-volume / lower-volume grouping is consistent, and both
generated table bodies appear verbatim in the manuscript when a copy of `paper.tex` is
available (set `PAPER_TEX=<path>`; the manuscript ships in the Overleaf package). It
exits nonzero on any
mismatch. Run it after touching anything in this directory.
